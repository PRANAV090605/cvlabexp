# Computer Vision Experiments

A collection of hands-on Computer Vision experiments implemented using Python, OpenCV, NumPy, and Matplotlib. This repository explores fundamental image processing techniques, noise reduction, edge detection, image segmentation, and texture analysis.

## 📚 Lab Experiments

| No. | Experiment                                             | Notebook       |
| :-: | ------------------------------------------------------ | -------------- |
|  01 | Image Loading, Visualization and Basic Transformations | `exp-01.ipynb` |
|  02 | Adding and Analyzing Salt-and-Pepper Noise             | `exp-02.ipynb` |
|  03 | Image Denoising Using Median Filtering                 | `exp-03.ipynb` |
|  04 | Gaussian Noise Generation and Image Smoothing          | `exp-04.ipynb` |
|  05 | Edge Extraction Using Sobel Operators                  | `exp-05.ipynb` |
|  06 | Automatic Image Segmentation Using Otsu Thresholding   | `exp-06.ipynb` |
|  07 | Image Texture Classification Using GLCM Features       | `exp-07.ipynb` |
|  08 | Straight-Line Detection Using the Hough Transform      | `exp-08.ipynb` |

## 🛠️ Technologies Used

* **Python** – Primary programming language.
* **OpenCV** – Image processing and computer vision operations.
* **NumPy** – Numerical computations and image array manipulation.
* **Matplotlib** – Image visualization and plotting.
* **Jupyter Notebook** – Implementation and execution of experiments.

## 🚀 Getting Started

**1. Clone the repository**

```bash
git clone <your-repository-url>
```

**2. Navigate to the project directory**

```bash
cd <repository-name>
```

**3. Install the required libraries**

```bash
pip install opencv-python numpy matplotlib jupyter
```

**4. Launch Jupyter Notebook**

```bash
jupyter notebook
```

**5.** Open any experiment notebook and execute the cells to explore the corresponding computer vision technique.

## 🎯 Learning Objectives

* Understand image representation and basic image transformations.
* Study different types of image noise and filtering techniques.
* Explore edge detection and image segmentation algorithms.
* Extract meaningful texture information using GLCM.
* Understand line detection through the Hough Transform.

**Note:** Each experiment contains its own implementation and visual outputs to demonstrate the working of different computer vision algorithms.
